# 東京スカイツリー散策（第4版：飛行探索・浅草通り〜吾妻橋）

「東京スカイツリーと周辺地域の再現ゲーム開発指示書（仕様案 第1版）」と、2026年10月2日の改善依頼に基づくブラウザ用の一人称散策3Dゲームです。

- `index.html`：ゲーム本体（three.js r128 を CDN から読み込み）
- `data/`：実データ（建物・地図・航空写真。`l2.b64.txt` は PLATEAU 2025 の LOD2、`town.json` はスカイツリータウンの屋根面）。**`index.html` と同じ場所に置いて、Webサーバー経由で開いてください**（ファイルを直接ダブルクリックするとブラウザの制限でデータを読めません。例：`python3 -m http.server` で起動して `http://localhost:8000/` を開く）
- `docs/`：修正前／修正後の画像、空中写真との比較画像
- `tools/`：データを作り直すためのスクリプト

## 第4版で変えたこと（2026-10-04）：飛行探索・浅草通り〜吾妻橋・写実表現

### 0. 先に直した不具合（第3版から続いていたもの）
| 不具合 | 原因 | 対処 |
|---|---|---|
| 建物の壁が抜けて、板が浮いているように見える | PLATEAU LOD2 の壁を三角形に分割したとき、一部の三角形が内向きになっていた | 分割後の三角形を元の面の向きにそろえた。屋根面との位置関係から外向きを判定して、壁の向きも直した |

### 1. 探索範囲を浅草通り〜吾妻橋・アサヒビール本社周辺まで広げた
- 距離と方位は縮めていません（緯度経度から平面に近似）。
- **地面**：国土地理院の空中写真（z18）を追加しました。範囲は西へ約1.7kmです。
- **建物**：半径1.45km以内の PLATEAU 2025 LOD2 を描画します。
- **道路・橋・川**：国土地理院の道路中心線と水域から作りました。吾妻橋も道路中心線から生成しています。
- **徒歩経路**：スカイツリー南側から吾妻橋の西詰まで、約1.2kmです。道路中心線の最短経路を歩道側へずらしたもので、歩道の正確な位置は推定です。目的地メニューに「アサヒビール本社の南側」「吾妻橋」「吾妻橋 西詰」を追加しました。
- **首都高速6号向島線**：国土地理院の高架道路の中心線から作りました。高さ約9.5m・幅16mは写真からの推定です。

**アサヒビール本社周辺は、2つの建物を別々に作りました**
| 建物 | 根拠 | 確認できたこと | 推定 |
|---|---|---|---|
| アサヒビールタワー | PLATEAU の外形・実測高さ95.6m | 金色の反射ガラスと上部の白い冠（写真） | 冠の段差の数・高さ、窓割り |
| スーパードライホール | PLATEAU の外形・総高さ46.2m | 黒い逆台形の建物と、屋上の金色の炎（写真） | 建物部分の高さ22.5m、炎の太さ・反り・正確な向き |

**吾妻橋**：赤い3連アーチ、赤い欄干、灯柱は写真で確認しました。アーチの高さと灯柱の間隔は推定です。

### 2. 自由飛行
- **切り替え**：PC は F キー、スマートフォンは「飛行」ボタンです。
- **PC の操作**：

| 操作 | キー |
|---|---|
| 前後左右 | W A S D |
| 上昇 | Space |
| 下降 | C または Q |
| 速度（低速6 m/s・標準25 m/s・高速90 m/s） | 1・2・3（Shift で2倍） |
| 近くの安全な場所へ | R |
| 開始地点へ | H |
| 視点 | マウス |

- **スマートフォンの操作**：移動はスティック、視点はドラッグです。画面右に「上昇」「下降」「速度」「近くへ」「開始地点」のボタンを置きました。
- **動き**：加減速はなめらかにしています。視点は傾かず、水平を保ちます。
- **画面の表示**：地面からの高度、速度、方位、境界までの距離を出します。
- **範囲**：上限高度は900mで、スカイツリーの頂部（634m）より上から全景を見られます。境界はタワーから1.7kmで、近づくと半透明の壁と案内が出ます。
- **当たり判定**：建物・橋・高架・首都高・地面は、徒歩と同じ判定を高さに合わせて使っています。タワーは高さごとの太さを円錐で近似しています。
- **着地**：真下に安全な床がある場合だけ降ります。床がない、または障害物がある場所では着地できず、「近くの安全な場所へ」を案内します。

### 3. 人物
- **近く（35m以内、最大70人）**：詳細な形で描きます。
  - 頭蓋からあごまでの輪郭、目・眉・鼻・口・耳
  - 髪型4種（輪郭の段差と、筋状の濃淡）
  - 胴は腰・くびれ・胸・肩をなめらかにつなぎ、襟・裾・脇の縫い目・前の合わせを付けました
  - 肩の丸み、ひじ・ひざ周りのしわ、袖口・裾、手、靴、鞄
  - 布には細かな織り目の凹凸を付け、肌・髪・靴・鞄とは粗さを分けています
- **遠く**：軽い形に切り替えます。
- **歩き方**：歩幅に合わせて脚の周期を進め、足が滑らないようにしています。脚を開いた分だけ腰を下げて、地面へのめり込みを抑えています。
- **動きの切り替え**：立ち止まりと歩き出しは加速・減速でつなぎ、方向転換は向きを少しずつ回します。
- **人ごとの違い**：速度、歩幅、腕の振り、前傾（高齢者は大きめ）、体格、服装、髪型を変えています。
- **周りとの関係**：すれ違う人とは横にずれて重なりを避けます。信号のある交差点に横断歩道を置き、車の信号が赤の間だけ渡ります。
- **限界**：手続き的に作った形なので、近くで見ると人形のような印象が残ります。写真のような人体にはなっていません（残る課題を参照）。

### 4. 車
- **車種**：セダン、軽自動車、ミニバン、タクシー、トラック、バスの6種です。車種ごとに断面の形（車幅、腰線、屋根の高さ、窓の位置）を前後方向へつなぎ、曲面の車体にしました。
- **部品**：ボンネット、屋根、フェンダーの丸み、ドアの境目、ピラー、ミラー、グリル、ライト、バンパー、タイヤハウスを付けました。
- **室内**：座席とダッシュボードを置き、窓から見えます。
- **素材**：塗装（ソリッド／メタリック。下地の上に艶のあるクリア層）、黒い樹脂、ゴム、メッキ、ガラスに分けています。
- **タイヤ**：側面のふくらみがあるゴムと、スポークのあるホイールを別の素材にしました。
- **走り方**：
  - タイヤは走行距離に合わせて回し、曲がるときは前輪の向きを変えます
  - 車線のつながりをたどって交差点を曲がります
  - 信号（東西／南北の2現示、黄色4秒）で停止線の手前に止まります
  - 前の車との間隔は車の長さに応じて取ります
- **灯火**：ブレーキランプは減速中と停止中に、方向指示器は曲がる前に点滅、ヘッドライトは夜に点きます。
- **演出の部分**：信号の周期と位置は演出です。

### 5. 建物と窓
- **窓の奥の部屋**：ガラス面の後ろに、床・天井・奥の壁・側壁・カーテンを視線に合わせて描きます。部屋の形は実際には作らず、計算で見せています。
- **夜の窓**：部屋ごとに、点灯の有無・色温度・明るさを変えています。
- **既存の凹凸**：外壁テクスチャの窓のくぼみ・サッシ・窓台・バルコニーは、第3.2版の凹凸を使っています。
- **主要施設の専用外観**：アサヒビールタワー、スーパードライホール、吾妻橋、スカイツリータウン（入口棟・連絡ブリッジ・ソラミ坂）です。

### 6. 道路と植栽
- **路面標示**：中央線、車線境界線（破線）、外側線、停止線、横断歩道を付けました。
- **縁石**：高さ15cmで、交差する道路の上では切っています。
- **信号機**：柱・腕・灯器を作り、車の現示と同期して点灯します。
- **街路樹**：幹と枝、凹凸のある葉の塊（下側が暗い）、葉の細かな凹凸、足元の木陰を作りました。
- **推定の部分**：路面標示と信号は、道路の幅員から一般的な寸法で作っています。実際の本数・位置とは一致しない箇所があります。

### 7. 空と光
- **雲**：空に雲を描きます。量は天候、流れは時刻で変わり、形は演出です。夜は暗くしています。
- **時刻と天気**：昼、夕方、夜、曇りで色と明るさが変わることを確認しました（`docs/v4_tod_*.jpg`）。

**品質の面で残る課題（正直な評価）**
- **人物**：顔・髪・服の縫い目は付けましたが、手続き的に作った形なので、近くで見ると人形のように見えます。写真のような人体にするには、スキャンや人体モデル（ライセンス付き）が必要です。歩行の重心移動は簡易です。
- **車**：断面をつないだ曲面なので、実際の車の細かな面の折れ、ライトの内部構造、ホイールの意匠はありません。窓の反射は空の環境マップだけで、周りの建物は映りません。
- **建物**：アサヒビールタワーなど主要施設以外は、汎用の外壁4種類です。窓の奥の部屋は計算で見せているだけで、店舗の陳列や看板はありません。
- **影と光**：建物の足元・車の下の接地影は、太陽の影と木陰のみです。周囲から回り込む光（環境遮蔽）は入れていません。濡れた路面は実装していません。
- **屋上**：PLATEAU LOD2 の屋根の形・段差まで。空調設備・塔屋・手すりは、資料で確認できないため置いていません（PLATEAU の精度どまり）。
- **遠景**：半径1.45〜1.75kmの外は外形の押し出しで、切り替え位置で形が変わる箇所があります。
- **地面の高さ**：平坦（0m）として扱っています。隅田川の護岸の段差と、吾妻橋の高さが小さくなっています。

**未確認の形状・仮素材**

## 第3.2版で変えたこと（2026-10-03）：質感・通行人・車

### 質感（材質が伝わるように）
外部のテクスチャ配布サイトにはこの環境から接続できなかったため、すべて手続き的に自作しました（`tools/gen_tex.py`、`data/tex/`）。1つの素材につき「色」「凹凸（法線マップ）」「粗さ・金属感」の3枚を使い、光の反射の仕方まで素材ごとに変えています。

| 素材 | 使った場所 | 内容 |
|---|---|---|
| 舗石 | 4F スカイアリーナの床、入口棟の床 | 0.6×0.3m の石の馬目地、石ごとの色の差、目地のくぼみ |
| コンクリート | 高架の柱・桁、階段の側面など | 型枠の継ぎ目とセパ穴、雨だれのしみ、細かな気泡 |
| アスファルト | 車道、ホーム、地面（近く） | 骨材の粒と凹凸 |
| 塗装した鋼材 | タワー、手すり、鉄骨 | 塗装面のゆず肌と、わずかな光沢 |

- **実機での fps 測定・15分間の連続歩行**：GPU のある実機がないため未実施です（ゲーム内の F3 で計測できます）。
- 第2版の空中写真との比較（`docs/aerial_vs_game_1〜3.jpg`）は第2版で実施したもので、第3版では撮り直していません。

## データの作り直し方（`tools/`）

1. `conv.py`：国土地理院のベクトルタイル（z16）をゲームの座標に変換する
2. `parse_plat.py`：PLATEAU の CityGML（タワーの周囲12区画）から、建物の外形と実測高さを取り出す
3. `fetch_far.py`：遠景用に、半径6kmと高層ビル群の区画を S3 から部分的にダウンロードする
4. `mosaic.py`：空中写真のタイル（z18・z16・z14）をつなげる
5. `build_assets.py`：`data/bldg.b64.txt`・`far.b64.txt`（建物の外形と高さを16bit整数で詰めてbase64にしたもの）・`world.json` を作る
6. `compose.py`：比較画像を作る
7. `dl25.py`：PLATEAU 2025（墨田区）の CityGML から必要な3次メッシュだけを部分ダウンロードする
8. `parse_lod2.py`：CityGML から LOD2 の屋根面・壁面と LOD1 の外形を取り出す（`python3 parse_lod2.py <gmlをカンマ区切り> 2000 lod2all.json`）
10. `gen_tex.py`：質感用テクスチャ（色・法線・粗さ/金属）を作る
11. `route_asahi_path.json`：スカイツリー南側〜吾妻橋の徒歩経路（道路中心線の最短経路）
9. `build_lod2.py`：LOD2 を三角形にして `data/l2.b64.txt`、スカイツリータウンの屋根面一覧を `data/town.json` に出力。続けて `build_assets.py` を実行すると、2025年度の範囲の 2020年度データが置き換わる
