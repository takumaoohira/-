# 東京スカイツリー散策（試作版）

「東京スカイツリーと周辺地域の再現ゲーム開発指示書（仕様案 第1版・2026年9月23日）」に基づく、ブラウザで動く一人称散策型の3Dゲームです。
`index.html` を1枚開くだけで動きます（three.js r128 を CDN から読み込みます）。

指示書 §13 の段階でいうと「地形と仮配置」から「主要部分の試作」までに当たります。現地調査・図面・構内図との照合はまだ行っていないため、**完全再現ではありません**。確認できたこととまだ確認できていないことは、ゲーム内の「検証」パネルと下の一覧で分けて示しています。

目線の高さは1.6m、歩行速度は1.4m/秒が初期値です（設定パネルで変えられます）。

## 実装した内容

- **タワー本体**：高さ634m。足元の正三角形から高さ約300mで円形になる断面、24本の柱とX形ブレースの鉄骨（模式）、天望デッキ・天望回廊の張り出し、上部のゲイン塔、航空障害灯
- **展望台**：天望デッキ フロア340・345・350と階段、フロア340のガラス床（位置は推定）、天望回廊のスロープ（フロア445→450）とソラカラポイント（451.2m）。「フロア350」は地上350mのことで、350階としては扱っていません
- **移動の流れ**：押上駅の地下コンコース → 連絡通路 → スカイツリータウン B3 → エレベーター → 4F 屋外広場 → 4F 入口フロア → 天望シャトル → フロア350 → 天望回廊シャトル → フロア445〜451.2 → 下りシャトル → フロア345 → 340 → 下りシャトル → 5F 出口フロア → 屋外階段 → 4F 広場。とうきょうスカイツリー駅のホーム → 階段 → 地上改札 → 川沿い → 屋外大階段 → 4F 広場も通れます
- **エレベーターで場面が切り替わるとき**：出発階・到着階・高度を表示し、到着後の位置と向きを決めています
- **周辺**：北十間川（水面にタワーが映る）、西十間橋・東武橋・京成橋、浅草通り・四ツ目通り（車道・歩道・車線・横断歩道・信号）、高架の東武スカイツリーライン、大横川親水公園、街並み（仮配置）
- **眺望**：隅田川、浅草寺、アサヒビール本社、東京タワー、新宿・丸の内などの高層ビル群、富士山を緯度経度から方位・距離を計算して配置。展望台では方位ラベルが出ます
- **時刻・天候・ライティング**：太陽の向き、影、空の色、窓明かり。天候（晴れ・かすみ・くもり）で見通しが変わります。ライティングは常設の「粋」「雅」と消灯。「自動」は日没〜24時に点灯します
- **人・車・列車**：人は歩道・広場・展望台、車は車道を走り、信号に従います。列車は高架を走って駅に停まります（どれも演出で、実際のダイヤや交通量ではありません）
- **環境音**：交通・川・列車・展望台の風・地下の残響・音響信号（演出）
- **案内**：目的地14か所への経路を矢印と地図で表示します。自動歩行もできます（確認動画の撮影用）
- **施設情報**：名称・分類・座標・入口・階・説明・資料ID・確認日・状態をデータとして持っています。営業時間や料金は未確認なので表示しません
- **検証機能**：状態別の色分け表示（確認済み／推定／資料不足／演出・仮配置）、12か所の比較視点（位置・方位・俯仰角・画角）、経路検査（0.2m刻みで床と障害物を判定）、検査結果のMarkdown出力、性能表示（fps、低下時の値、描画コール数、メモリ、読込み時間、連続歩行の時間と距離）、写真の保存

## 座標の基準（§6）

- 原点：タワー中心（北緯35.710063°、東経139.8107°。概略値で、測量による確認はしていません）
- +X＝東、−Z＝真北、1単位＝1m、高さは地面を0mとする（T.P.への補正はしていません）
- 緯度経度とゲーム座標の変換は平面近似（緯度1°＝111km）
