# コースデータの作り方

ゲーム本体（`fpv-sim.html`）を書き換えずにコースを追加・編集するための説明です。

## 手順

1. このフォルダに `コースID.json` を作ります（例：`tenrei.json` をコピーして編集）。
2. `python3 tools/embed_courses.py` を実行します。`courses/*.json` がすべてゲームに埋め込まれます。
3. タイトル画面の「コース選択」に新しいコースが自動で並びます。

## 座標の決まり

ホールは「模式図」の座標で書きます。横200 × 縦340 の紙に、ティーを下（y≈318）、グリーンを上（y≈50）に置くイメージです。
距離 `y`（ヤード）に合わせて全体が自動で拡大されるので、形だけ決めれば大丈夫です。

## コース全体

| 項目 | 内容 |
|---|---|
| `id` | 英数字のコースID |
| `name` | コース名 |
| `desc` | タイトル画面のカードに出る説明 |
| `theme` | 景観（`alpine` 山岳、`odawara` 森林、ほか `THEMES` の名前） |
| `card` | カードの絵（CSSの背景） |
| `holes` | 18ホール分の配列 |

## ホールごとの項目

| 項目 | 内容 | 例 |
|---|---|---|
| `n` `p` `y` `hc` | 番号・パー・距離（ヤード）・ハンディキャップ | `"p":4,"y":385` |
| `name` | ホールの特徴（看板とキャディの説明に出る） | `"谷越えショート"` |
| `az` | ホールの向き（度。太陽の当たり方が変わる） | `200` |
| `pts` | フェアウェイの中心線。最初がティー、最後がグリーン | `[[100,318],[104,190],[98,58]]` |
| `fw` | フェアウェイの半分の幅（ヤード） | `18` |
| `fwProf` | 途中で幅を変える `[[位置0〜1, 半幅]]` | `[[0,13],[0.6,9],[1,13]]` |
| `alts` | 別ルートのフェアウェイ `[{pts,w}]` | 17番の上段ルート |
| `elev` | 標高の変化 `[[位置0〜1, 高さY]]`。急に変えると2段・3段のフェアウェイ | `[[0,0],[0.55,-30],[1,-40]]` |
| `tilt` | フェアウェイの左右の傾き（右へ1Yあたりの高さ） | `0.05` |
| `spine` | 尾根の上のフェアウェイ（外側へ下がる高さY） | `26` |
| `ridges` | 丘 `[x,y,横半径,縦半径,高さY,角度]`（ブラインドホール用） | `[[100,198,90,12,9,0]]` |
| `valleys` | 谷 `[x,y,横半径,縦半径,深さY,角度,小川0/1]`。落ちると1打罰で打ち直し | `[[100,192,95,50,30,0,1]]` |
| `cliffs` | 崖 `[x,y,横半径,縦半径,深さY]` | `[[100,34,70,8,25]]` |
| `ponds` | 池 `[x,y,横半径,縦半径,角度]` | `[[100,170,52,46,0]]` |
| `bunk` | バンカー `[x,y,横半径,縦半径,角度]` | `[[78,176,7,11,8]]` |
| `ob` / `obBack` | OBの側（`"L"`, `"R"`, `"LR"`）／グリーン奥のOB | `"LR"` |
| `raised` | グリーンの高さ（砲台グリーンは大きく） | `4.5` |
| `green` | グリーン `{ra,rl,tilt:[奥への傾き,右への傾き],tiers:[[位置,段差]],ridge}` | `{"tiers":[[-6,0.6],[5,0.6]]}` |
| `pins` | ピン位置の候補（グリーン中心からの `[奥,右]` ヤード）。毎回ランダムに1つ | `[[-6,-3],[4,4]]` |
| `aims` | 安全ルートの狙い目（オレンジの①②③） | `[[108,196],[98,60]]` |
| `attack` | 攻撃ルートの狙い目（赤のA1, A2） | `[[92,150]]` |
| `club` | ティーショットのおすすめクラブ | `"3W"` |
| `tips` / `danger` | 攻略メモと注意点（キャディが話す） | |
| `td` | 樹木の密度の倍率 | `1.3` |
| `wind` | 風速の範囲（m/s） | `[2,6]` |
| `nobunker` | 1 にすると自動のグリーン周りバンカーを置かない | `1` |
