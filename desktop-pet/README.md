# ポケットペット

スマホの画面にねこ・いぬがやってきて、歩いたり寝たり、さわると反応したりするアプリです。

## 2つの版

| | Android アプリ (`app/`) | Web 版 (`web/index.html`) |
|---|---|---|
| 対応端末 | Android 8.0 以上 | iPhone / Android / PC |
| 表示場所 | **ホーム画面や他のアプリの上** | アプリ(ページ)の中の「ペットのお部屋」 |
| 常駐 | ○ (通知から ごはん / おいで / しまう) | 開いている間だけ |

iPhone (iOS) は、OS の決まりでどのアプリもホーム画面や他のアプリの上に重ねて表示できません。
そのため iPhone では Web 版を使います。Safari で開いて「共有 → ホーム画面に追加」すると、アプリのように全画面で起動できます。

## できること(両方共通)

- **タップ**: 喜ぶ、びっくりする、手をふる、くるくる回る(いぬ)など。連打すると怒って逃げます
- **ダブルタップ**: ごはん(ねこ=おさかな / いぬ=ほね)をもぐもぐ
- **長押し**: なでなで。ハートが出て、しばらくなでると目がハートに
- **つまんで動かす / 投げる**: ぶらーんとぶら下がり、離すと放物線で飛んで着地。強く投げたり振り回すと目を回します
- ねこは**壁をよじ登り**、投げられると壁にしがみつくことも
- **気分(おなか・げんき・なかよし)**: 時間とともに変わり、行動が変わります
  - おなかがすくと「ごはんまだ?」とおねだり
  - かまわないと「かまって〜」
  - 疲れたり夜になると丸くなって眠る(Zzz)
- 時間帯のあいさつ、ときどきおしゃべり(「おしごとがんばって!」など)
- 種類: 茶トラ・黒猫・白猫・三毛猫・サバトラ / 柴犬・黒柴・ビーグル・ゴールデン・白いわんこ
- 名前・大きさ・性格(おっとり / ふつう / げんき)を設定可能

## Android アプリの入れ方

1. GitHub のこのリポジトリの **Actions → Build Pocket Pet APK** を開き、最新の実行結果の
   **Artifacts → pocket-pet-apk** をダウンロード(zip の中に `app-debug.apk`)
2. スマホで APK を開いてインストール(「提供元不明のアプリ」の許可が必要)
3. アプリを開き、「許可する」から**ほかのアプリの上に重ねて表示**を ON
4. 「ホーム画面に出す」を押す

自分でビルドする場合は Android Studio でこのフォルダを開くか、`./gradlew assembleDebug`。

## しくみ

- `Pet.kt` … 頭脳。行動の状態遷移・物理(重力/投げ/壁)・気分・タッチの解釈
- `PetRenderer.kt` … 画像素材なしで、姿勢に合わせてペットをコードで描画
- `PetService.kt` … 小さな透明ウィンドウを他のアプリの上に置き、毎フレーム動かす常駐サービス
- `web/index.html` … 上記と同じロジックを JavaScript に移した Web 版
